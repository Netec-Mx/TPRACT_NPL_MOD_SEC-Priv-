# Taller Práctico Procesamiento del lenguaje natural con modelos de secuencias

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Taller Práctico Procesamiento del lenguaje natural con modelos de secuencias**. Aquí aplicarás modelos de secuencias para identificar solicitudes bancarias que expresan una misma necesidad, aunque estén redactadas de forma diferente, mediante una práctica guiada con Python en Visual Studio Code.

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

## Capítulo 1

### [Práctica 1. Construcción de un sistema para analizar y detectar solicitudes bancarias duplicadas](Capitulo01/README.md)

- **Descripción**: Construye en un cuaderno de Jupyter un sistema para comparar solicitudes bancarias sintéticas y detectar duplicados. Prepara y limpia los textos, separa los grupos en entrenamiento, validación y prueba, y representa las palabras con Word2Vec. Después, entrena una red siamesa con LSTM, evalúa sus resultados frente a una comparación por palabras compartidas y prueba distintos umbrales de decisión y palabras desconocidas. Finalmente, guarda el modelo y documenta tus conclusiones.
- ⏱️ **Duración estimada**: 105 min (1 hora y 45 minutos).
- 📁 **Prerrequisitos**: [Preparación del entorno de laboratorio](Capitulo01/Prerrequisitos.md).
